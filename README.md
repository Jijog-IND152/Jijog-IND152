| Attribute | Details |

| **Deployment** | Vercel (production) |

UI responsiveness was iteratively improved based on real usage across devices.

</details>

<details>

<br/>

A production Zoho Cliq extension that bridges Zenkit project management with the Cliq team messaging platform. Real-time task synchronization is handled via REST API-based CRUD operations and webhook callbacks, with OAuth 2.0 securing the integration layer. Workflow automation is scripted using Zoho Deluge with strict request validation.

| Attribute | Details |
|---|---|
| **Stack** | Zoho Cliq SDK, Zenkit REST API, Zoho Deluge scripting |
| **Auth** | OAuth 2.0 authorization flow |
| **Sync** | Bidirectional task CRUD + real-time webhooks |
| **Automation** | Zoho Deluge workflows with request validation |
| **Distribution** | Published on Zoho Cliq Marketplace |
| **Status** | Active — continuously maintained since Nov 2025 |
| **Repository** | [Install on Zoho Cliq](https://cliq.zoho.com/installapp.do?id=7992) |

Architected the full integration layer including OAuth token handling, webhook receiver validation, and error recovery. Automated complex multi-step task workflows using Deluge scripting, reducing manual coordination overhead for teams using both Zenkit and Zoho Cliq in parallel.

</details>

<details>
<summary><strong>TurfXie — Turf Booking Platform</strong> <em>(In Development)</em></summary>

<br/>

A full-stack turf booking platform with multi-stakeholder architecture — serving players, turf owners, and platform administrators through separate, role-isolated modules. Built on Spring Boot with a React/TypeScript frontend, MySQL for persistent data, and Redis for session and cache layers.

| Attribute | Details |
|---|---|
| **Stack** | Spring Boot, React, TypeScript, MySQL, Redis |
| **Architecture** | Multi-module monolith — Auth, Booking, Payments, Owner, Admin |
| **Auth** | JWT-based authentication with role-based access control |
| **Database** | 18-table normalized schema across 6 functional modules |
| **Cache** | Redis for session management and availability caching |
| **Documentation** | Full ER diagrams, module-level flow docs, API contracts |
| **Status** | Active development — production-quality architecture |

Designed the complete system architecture independently, including an 18-table ER schema covering Users, Turf, Slots, Bookings, Payments, Reviews, and Owner management. Module-level flow documentation and interactive ER diagrams were produced as engineering artifacts. The platform follows enterprise Spring Boot conventions throughout — Lombok, JPA, layered service architecture, and Redis integration patterns.

</details>
