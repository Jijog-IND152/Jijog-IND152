## About

I'm a Software Engineer working on enterprise workflow applications, covering the frontend, the backend APIs and the database. I build features end to end: data models, REST APIs, role-based access, validation and React interfaces.

Testing and security are part of how I build, not an afterthought. I write test cases, check APIs for access-control and validation gaps, and ship patches that keep the frontend and backend rules in sync.

**Focus:** `Full Stack` · `Backend APIs` · `Workflow Systems` · `Testing & Security`
